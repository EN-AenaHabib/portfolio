# Aena Town

My portfolio, built as a scroll-driven pixel-art journey: a dive through the clouds, a town where every house holds a project, the lantern woods, the road of my story, and a coffee house at the end.

**Live:** https://en-aenahabib.github.io/portfolio/

## Files
- `index.html`: the whole site (HTML, CSS and JavaScript in one file)
- `lofi.mp3`: background music
