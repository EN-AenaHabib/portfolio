House 1 · the greenhouse

AenPi

An Urdu NLP library that runs on modest hardware, with no large language model required.

AenPi is a framework for low-resource language processing, starting with Urdu. It uses lightweight models such as conditional random fields, which keeps computation and energy use low while still performing well on Urdu text. Green AI is the principle behind every design choice.

Python · CRF · Green AI · 2026 · ★ 4

House 2 · the workshop

DevFlow-AI

A developer assistant for the work around code: documentation, tests, refactoring and review.

Built for the IBM Bob hackathon in 2026. Given a codebase, DevFlow-AI generates documentation, writes tests, suggests refactors and produces code reviews. Each task runs through an LLM pipeline built with LangChain, with IBM Bob underneath.

LLMs · LangChain · agentic automation · 2026

House 3 · the factory

Factory Compliance

Compliance monitoring that connects what a factory camera sees with what the policy says.

An end-to-end system in three parts. It ingests raw factory video, parses a regulatory policy document through a RAG pipeline, and uses both to drive real-time alert and escalation workflows. Like AenPi, it was designed with Green AI in mind.

Python · RAG · video processing · 2026
Open the repo ↗
House 4 · the help desk

NUTECH Assistant

A university FAQ assistant that answers from NUTECH's own documents.

Built in n8n with a local HTML interface. It ingests university documents, turns them into embeddings, and retrieves the relevant passages with FAISS before Groq's language model writes the answer. Grounding each reply in retrieved text gives context-aware answers with less hallucination.

n8n · FAISS · Hugging Face · Groq · 2025
Open the repo ↗
House 5 · the depot

Order Stream

E-commerce orders and transactions, processed and visualized as they happen.

An event-driven architecture for real-time data. Orders and transactions stream through Apache Kafka, are transformed in Python, stored in PostgreSQL and shown on live Grafana dashboards, covering the full path from ingestion to analytics.

Apache Kafka · Python · PostgreSQL · Grafana · 2025
